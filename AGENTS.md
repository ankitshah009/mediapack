# AGENTS.md — MediaPack

Read `PLAN.md` first for the product spec, then `DECISIONS.md` for the user's current architecture decisions. `apps/web` is the dashboard; `apps/web/components/console/CONTRACT.md` is the component contract. Historical provisioning and worker choices in the plan do not override the verified setup below.

## Stack
- `apps/web`: Next.js App Router (TypeScript, Tailwind), Node runtime. Dashboard + REST + MPP endpoint.
- `apps/mcp`: mcp-use server, thin proxy over REST, hosted on Manufact. Health, MCP transport, nine tools and caller-owned video access are verified; recheck the API origin after a new web release.
- `worker/`: Node/TypeScript, ffmpeg/ffprobe and pinned local CPU whisper.cpp 1.9.5 with bundled multilingual base weights. Runs in 4 GB Blaxel sandboxes; no audio API is used.
- Supabase: direct existing-account Free project, Postgres + private Storage + Realtime. The user explicitly chose direct Supabase; do not provision through Stripe Projects or upgrade the plan.
- Payments: Stripe test mode, MPP + Link. Agent messaging: Primitive.

## Rules
- UI renders only from persisted `events` rows. Simulated replay lives only in `apps/web/lib/demo/`.
- Every API error: `{error, hint, next_action}`.
- Purchase is idempotent on `quote_id`. Allowance is enforced in SQL (`consume_allowance`).
- Never claim root cause from video. Always label test mode.
- Verify an integration's real API before writing against it; log findings below.
